How many times each page was opened.

This page is not part of the site a homeowner sees. It is the only demand signal this project has, because the request form has no server: the form composes the request on the visitor's own device and hands it to their mail app, so nothing reaches us unless the visitor sends it.

What is counted

Page opens, one per visit, nothing else.

Each page carries a single anonymous beacon that counts one thing: that the page was opened. No cookie, no identifier, no personal data, no record of who or where. It counts page opens, not people, and not requests. The number of requests actually received is a separate, hand-maintained figure on the contractor page.
